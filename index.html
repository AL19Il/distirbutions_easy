Continuous uniform distribution

X ∼ U(a, b) — Equal-length intervals within the support have equal probabilities.

Bounds adjust automatically to keep a < b. The minimum interval width in this demo is 0.5.

What are you seeing?

The blue rectangle is the probability density (PDF). The green area up to x is the cumulative probability (CDF).


Try increasing b while holding a fixed. The height decreases, but the total area stays 1.

Mean
E[X] = (a+b)/2
Variance
Var(X) = (b−a)²/12
Density height
f(t) = 1/(b−a)

Formulas with your values

f(t) = 1/(b−a)   for a ≤ t ≤ b;   0 otherwise.
F(x) = 0   if x ≤ a
F(x) = (x−a)/(b−a)   if a < x < b
F(x) = 1   if x ≥ b

For a continuous variable, P(X=x)=0. Probability comes from area over an interval, not the density height at a point.

A memorable example

Suppose a waiting time is uniformly distributed between 0 and 4 minutes. The probability of waiting at most 2 minutes is 50%. Every one-minute interval within that range has probability 25%.
